## Limitación de Despliegue

**Barrera Identificada:** Atlassian Forge requiere un método de pago (tarjeta de crédito/débito) registrado para desplegar aplicaciones, incluso cuando el uso está 100% cubierto por el **free tier** (200,000 GB-segundos mensuales gratuitos).

**Situación del Desarrollador:** 
- Sin acceso a tarjeta de crédito/débito
- Desarrollo realizado 100% desde dispositivo móvil (POCO X3 NFC)
- Sin acceso a PC para ejecutar `forge deploy`

**Impacto:** 
El proyecto no puede ser desplegado en un entorno de prueba real para los jueces, **a pesar de que el código es completamente funcional y está listo para producción**.

## Propuesta de Valor

Esta limitación burocrática **no invalida** la arquitectura propuesta:
- El código demuestra conocimiento profundo de Forge API
- La lógica Zero-Trust está correctamente implementada
- El manifest.yml cumple con todos los requisitos técnicos
- La solución resuelve un problema real de las empresas
